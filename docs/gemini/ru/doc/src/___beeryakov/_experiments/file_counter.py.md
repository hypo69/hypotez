# Модуль подсчета строк, классов и функций в файлах

## Обзор

Модуль `file_counter.py` рекурсивно подсчитывает количество строк в текстовых файлах в указанном каталоге и его подкаталогах, а также количество классов и функций в этих файлах.

## Подробнее

Этот модуль предназначен для анализа кодовой базы проекта `hypotez`, предоставляя информацию о количестве строк, классов и функций в каждом файле и каталоге. Это полезно для оценки размера проекта, анализа кода и выявления потенциальных проблем, связанных с сложностью кода.

## Функции

### `count_lines_in_files(directory)`

**Назначение**: Функция рекурсивно подсчитывает количество строк в текстовых файлах в указанном каталоге и его подкаталогах, а также количество классов и функций.

**Параметры**:

- `directory` (str): Путь к каталогу.

**Возвращает**:

- `tuple`: Кортеж из трех элементов:
    - `total_lines` (int): Общее количество строк в текстовых файлах.
    - `total_classes` (int): Общее количество классов.
    - `total_functions` (int): Общее количество функций.

**Как работает функция**:

- Функция проходит по всем файлам и каталогам в указанном каталоге.
- Для каждого файла она проверяет, является ли он текстовым (не бинарным), не находится ли в директориях `__pycache__` или `firefox_profiles`, а также не является ли Jupyter Notebook файлом.
- Если файл подходит под эти условия, функция подсчитывает количество строк в нем, а также вызывает функцию `count_classes_and_functions` для подсчета количества классов и функций в файле.
- Если файл является каталогом, функция рекурсивно вызывает саму себя для подсчета строк, классов и функций в подкаталогах.

**Пример**:

```python
>>> count_lines_in_files('src')
(1000, 50, 100)
```

### `is_binary(filepath)`

**Назначение**: Функция проверяет, является ли файл бинарным.

**Параметры**:

- `filepath` (str): Путь к файлу.

**Возвращает**:

- `bool`: `True`, если файл бинарный, иначе `False`.

**Как работает функция**:

- Функция пытается открыть файл в бинарном режиме (`'rb'`).
- Она читает первые 512 байт файла и проверяет, есть ли в них нулевые байты (`'\\0'`).
- Если нулевые байты есть, функция возвращает `True`, иначе `False`.
- Если возникла ошибка при чтении файла, функция предполагает, что файл бинарный, и возвращает `True`.

**Пример**:

```python
>>> is_binary('image.jpg')
True
>>> is_binary('text.txt')
False
```

### `count_classes_and_functions(filepath)`

**Назначение**: Функция подсчитывает количество классов и функций в файле.

**Параметры**:

- `filepath` (str): Путь к файлу.

**Возвращает**:

- `tuple`: Кортеж из двух элементов:
    - `total_classes` (int): Количество классов в файле.
    - `total_functions` (int): Количество функций в файле.

**Как работает функция**:

- Функция открывает файл в текстовом режиме (`'r'`) и проходит по каждой строке.
- Для каждой строки она проверяет, начинается ли она с ключевого слова "class" или "def".
- Если строка начинается с "class", значение `total_classes` увеличивается на 1.
- Если строка начинается с "def", значение `total_functions` увеличивается на 1.

**Пример**:

```python
>>> count_classes_and_functions('my_module.py')
(2, 5)
```

## Примеры

```python
>>> src_directory = 'src'
>>> total_lines, total_classes, total_functions = count_lines_in_files(src_directory)
>>> print(f"Total lines in text files in '{src_directory}': {total_lines}")
>>> print(f"Total classes: {total_classes}")
>>> print(f"Total functions: {total_functions}")
```
