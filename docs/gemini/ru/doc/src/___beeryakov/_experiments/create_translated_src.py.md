# Модуль `create_translated_src`

## Обзор

Модуль `create_translated_src` предназначен для копирования файлов из исходной папки в целевую папку с последующим выводом на консоль текста на русском языке из файлов, которые кодированы в UTF-8. 

## Подробнее

Модуль использует функции `os.walk` для обхода всех файлов в исходной папке, `shutil.copyfile` для копирования файлов в целевую папку и `chardet` для определения кодировки файла. 

Функция `detect_language` определяет кодировку файла с помощью модуля `chardet`. 

Функция `copy_and_print_russian_text` копирует все файлы из исходной папки в целевую папку и выводит текст на консоль, если файл закодирован в UTF-8. 

## Функции

### `detect_language`

**Назначение**: Определение кодировки файла.

**Параметры**:
- `file_path` (str): Путь к файлу.

**Возвращает**:
- str: Кодировка файла, если она определена как UTF-8, иначе `None`.

**Как работает функция**:
- Функция считывает содержимое файла с помощью `open` в бинарном режиме (`'rb'`).
- Вызывает функцию `chardet.detect` для определения кодировки.
- Если кодировка определена и содержит "utf-8", возвращает "utf-8", иначе возвращает `None`.

### `copy_and_print_russian_text`

**Назначение**: Копирование файлов из исходной папки в целевую папку и вывод текста на консоль, если файл закодирован в UTF-8.

**Параметры**:
- `src_dir` (str): Путь к исходной папке.
- `dest_dir` (str): Путь к целевой папке.

**Возвращает**:
- None.

**Как работает функция**:
- Использует `os.walk` для перебора всех файлов в исходной папке.
- Для каждого файла:
    - Определяет путь к целевому файлу с помощью `os.path.join`.
    - Создает директории для целевого файла, если они отсутствуют, с помощью `os.makedirs`.
    - Копирует файл в целевую папку с помощью `shutil.copyfile`.
    - Определяет кодировку файла с помощью `detect_language`.
    - Если кодировка равна `'utf-8'`:
        - Открывает файл с помощью `open` в режиме чтения (`'r'`) с указанной кодировкой (`'utf-8'`).
        - Считывает текст из файла с помощью `f.read()`.
        - Выводит текст на консоль с помощью `print`.

### `main`

**Назначение**: Точка входа в программу.

**Параметры**:
- None.

**Возвращает**:
- None.

**Как работает функция**:
- Определяет путь к исходной папке (`src_folder`).
- Определяет путь к целевой папке (`dest_folder`).
- Вызывает функцию `copy_and_print_russian_text` для копирования файлов и вывода текста.

## Примеры

```python
# Путь к исходной папке
src_folder = 'src'

# Путь к папке, в которую будем копировать файлы
dest_folder = 'src_en'

# Вызываем функцию для копирования и вывода текста на русском языке
copy_and_print_russian_text(src_folder, dest_folder)
```

```python
# Вывод текста на консоль из файла "src/some_file.py"
with open('src/some_file.py', 'r', encoding='utf-8') as f:
    text = f.read()
    print(text)
```
