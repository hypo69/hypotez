# Модуль для подсчета строк, классов и функций в файлах

## Обзор

Модуль `src.___beeryakov._experiments.file_counter_ru.py` содержит функции для рекурсивного подсчета строк, классов и функций в файлах и директориях. 

## Подробнее

Модуль предназначен для анализа кода проекта `hypotez`. Он рекурсивно обходит директории, подсчитывает количество строк в текстовых файлах, а также количество классов и функций, определенных в Python-файлах. 

## Функции

### `count_lines_in_files`

**Назначение**: Рекурсивно подсчитывает количество строк в текстовых файлах в указанной директории и ее поддиректориях.

**Параметры**:

- `directory` (str): Путь к директории.

**Возвращает**:

- tuple: кортеж из трех элементов:
    - `total_lines` (int): общее количество строк в текстовых файлах.
    - `total_classes` (int): общее количество классов.
    - `total_functions` (int): общее количество функций.

**Как работает функция**:

- Функция принимает путь к директории.
- Она итерирует по всем файлам и директориям в указанной директории.
- Для каждого файла проверяет, является ли он текстовым и не является ли файл из папок `__pycache__` и `firefox_profiles`.
- Если файл является текстовым, функция считывает его строка за строкой и увеличивает счетчик строк.
- Для каждого файла функция вызывает функцию `count_classes_and_functions` для подсчета количества классов и функций в нем.
- Если файл является директорией, функция рекурсивно вызывает себя для подсчета строк, классов и функций в этой директории.
- В конце функция возвращает общее количество строк, классов и функций.

**Примеры**:

```python
src_directory = 'src'
total_lines, total_classes, total_functions = count_lines_in_files(src_directory)
print(f"Всего строк в текстовых файлах в '{src_directory}': {total_lines}")
print(f"Всего классов: {total_classes}")
print(f"Всего функций: {total_functions}")
```

### `is_binary`

**Назначение**: Проверяет, является ли файл бинарным.

**Параметры**:

- `filepath` (str): Путь к файлу.

**Возвращает**:

- bool: `True`, если файл бинарный, иначе `False`.

**Как работает функция**:

- Функция принимает путь к файлу.
- Она пытается открыть файл в бинарном режиме (`'rb'`) и прочитать первые 512 байт.
- Если в прочитанных байтах найдены нулевые байты, функция возвращает `True`, предполагая, что файл бинарный.
- Если при чтении файла возникает ошибка, функция возвращает `True`, считая, что файл бинарный.

**Примеры**:

```python
filepath = 'test.txt'
is_binary(filepath)  # Возвращает True, если файл бинарный, иначе False
```

### `count_classes_and_functions`

**Назначение**: Подсчитывает количество классов и функций в файле.

**Параметры**:

- `filepath` (str): Путь к файлу.

**Возвращает**:

- tuple: кортеж из двух элементов:
    - `total_classes` (int): количество классов.
    - `total_functions` (int): количество функций.

**Как работает функция**:

- Функция принимает путь к файлу.
- Она открывает файл в текстовом режиме (`'r'`) и итерирует по каждой строке файла.
- Для каждой строки функция проверяет, начинается ли она с ключевого слова "class" или "def".
- Если строка начинается с "class", счетчик классов увеличивается.
- Если строка начинается с "def", счетчик функций увеличивается.
- В конце функция возвращает количество классов и функций.

**Примеры**:

```python
filepath = 'test.py'
total_classes, total_functions = count_classes_and_functions(filepath)
print(f"Количество классов в файле '{filepath}': {total_classes}")
print(f"Количество функций в файле '{filepath}': {total_functions}")
```

## Примеры

```python
# Подсчет строк, классов и функций в директории 'src'
src_directory = 'src'
total_lines, total_classes, total_functions = count_lines_in_files(src_directory)
print(f"Всего строк в текстовых файлах в '{src_directory}': {total_lines}")
print(f"Всего классов: {total_classes}")
print(f"Всего функций: {total_functions}")

# Проверка, является ли файл 'test.txt' бинарным
filepath = 'test.txt'
is_binary(filepath)  # Возвращает True, если файл бинарный, иначе False

# Подсчет классов и функций в файле 'test.py'
filepath = 'test.py'
total_classes, total_functions = count_classes_and_functions(filepath)
print(f"Количество классов в файле '{filepath}': {total_classes}")
print(f"Количество функций в файле '{filepath}': {total_functions}")
```
