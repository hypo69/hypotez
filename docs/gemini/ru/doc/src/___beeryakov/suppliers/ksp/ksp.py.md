# Модуль для работы с поставщиком KSP

## Обзор

Модуль `src.___beeryakov.suppliers.ksp` предоставляет функции для взаимодействия с веб-сайтом KSP (ksp.co.il) и извлечения информации о товарах. Использует модуль `src.webdriver` для автоматизации действий в браузере.

## Подробней

Модуль реализует функции для получения списков товаров, брендов и категорий. 

- `get_worlds()` - функция для получения всех доступных категорий товаров.
- `get_subs_from_world()` - функция для получения подкатегорий товаров из выбранной категории.
- `get_all_brands_list()` - функция для получения всех доступных брендов.
- `get_product()` - функция для извлечения информации о конкретном товаре по его URL.

## Классы

### `None` 

**Описание**: Модуль не содержит классов.

## Функции

### `get_worlds()`

**Назначение**: Функция извлекает список всех доступных категорий товаров с сайта KSP.

**Параметры**:

**Возвращает**: 
- `dict`: Словарь, где ключами являются названия категорий, а значениями - ссылки на эти категории.

**Вызывает исключения**:
- `Exception`: Если возникает ошибка при взаимодействии с веб-сайтом.

**Как работает функция**:
- Загружает файл `locators.json`, который содержит локаторы элементов для навигации по веб-сайту.
- Изображает элементы страницы, по которым можно перейти к категориям товаров.
- Собирает информацию о каждой категории (название и ссылка) и добавляет ее в словарь.

**Примеры**:

```python
>>> worlds_dic = get_worlds()
>>> print(worlds_dic)
```

### `get_subs_from_world()`

**Назначение**: Функция извлекает список подкатегорий товаров из выбранной категории.

**Параметры**:

**Вызывает исключения**:
- `Exception`: Если возникает ошибка при взаимодействии с веб-сайтом.

**Как работает функция**:

- Изображает элементы страницы, по которым можно перейти к подкатегориям товаров.
- Собирает информацию о каждой подкатегории (название и ссылка) и добавляет ее в словарь.

**Примеры**:

```python
>>> subs_dic = get_subs_from_world()
>>> print(subs_dic)
```

### `get_all_brands_list()`

**Назначение**: Функция получает список всех доступных брендов товаров с сайта KSP.

**Параметры**:

**Возвращает**: 
- `dict`: Словарь, где ключами являются названия брендов, а значениями - ссылки на страницы с товарами этого бренда.

**Вызывает исключения**:
- `Exception`: Если возникает ошибка при взаимодействии с веб-сайтом.

**Как работает функция**:
- Загружает файл `locators.json`, который содержит локаторы элементов для навигации по веб-сайту.
- Открывает страницу со списком всех брендов.
- Изображает список всех доступных брендов.
- Формирует словарь, где ключом является название бренда, а значением - ссылка на страницу с товарами этого бренда.

**Примеры**:

```python
>>> brands_dict = get_all_brands_list()
>>> print(brands_dict)
```

### `get_product(url: str = 'https://ksp.co.il/web/item/227307')`

**Назначение**: Функция извлекает информацию о товаре с сайта KSP по его URL.

**Параметры**:
- `url (str, optional): URL товара на сайте KSP. По умолчанию 'https://ksp.co.il/web/item/227307'.`

**Возвращает**: 
- `dict`: Словарь, содержащий информацию о товаре.

**Вызывает исключения**:
- `Exception`: Если возникает ошибка при взаимодействии с веб-сайтом.

**Как работает функция**:
- Загружает файл `locators.json`, который содержит локаторы элементов для навигации по веб-сайту.
- Открывает страницу товара по предоставленному URL.
- Изображает элементы страницы, содержащие информацию о товаре.
- Собирает информацию о товаре (название, цена, описание, изображения и т. д.) и добавляет ее в словарь.

**Примеры**:

```python
>>> product_info = get_product(url='https://ksp.co.il/web/item/227307')
>>> print(product_info)
```

## Внутренние функции

### `executor(locator: dict)`

**Назначение**: Функция выполняет действия с веб-элементом по заданному локатору.

**Параметры**:
- `locator (dict): Словарь, содержащий локатор веб-элемента.`

**Возвращает**: 
- `Any`: Возвращает значение веб-элемента или список значений, если веб-элемент представляет собой список.

**Вызывает исключения**:
- `Exception`: Если возникает ошибка при взаимодействии с веб-сайтом.

**Как работает функция**:
- Загружает файл `locators.json`, который содержит локаторы элементов для навигации по веб-сайту.
- Использует `executor` для взаимодействия с веб-элементом по указанному локатору.
- Возвращает значение веб-элемента или список значений.

**Примеры**:

```python
>>> executor(locators['worlds'])
```

## Параметры

### `locators.json`

**Описание**: Файл содержит локаторы элементов для навигации по веб-сайту.

### `worlds.json`

**Описание**: Файл содержит словарь с названиями категорий товаров и их ссылками.


## Дополнительная информация

- Для работы модуля необходимо установить библиотеки `webdriver` и `json`.
- В файле `locators.json` хранятся локаторы элементов для навигации по веб-сайту. Локаторы могут быть представлены в виде XPath, CSS Selector или других форматов.
- Модуль может быть использован для извлечения информации о товарах, брендах и категориях с сайта KSP.
- Информация, полученная с помощью этого модуля, может быть использована для создания каталога товаров, анализа рынка, ценовой политики и других задач.

## Заметки

- Модуль `executor` из `src.webdriver` предоставляет функцию для взаимодействия с веб-элементами по заданному локатору.
- Локаторы элементов в файле `locators.json` должны быть проверены и обновлены при необходимости.
- При использовании этого модуля необходимо учитывать правила использования веб-сайта KSP и избегать действий, которые могут привести к блокировке доступа к сайту.
