# Модуль `src.___beeryakov`

## Обзор

Модуль `src.___beeryakov`  предназначен для извлечения данных с сайта `ksp.co.il` (KSP)  и последующей записи этих данных в Google Таблицы. Модуль взаимодействует с сайтом KSP через `Webdriver`,  переходит по различным страницам, извлекает информацию о категориях,  брендах и товарах, а затем записывает полученные данные в Google Таблицы.

## Функции

### `def run()`

**Назначение**: Запускает парсер данных с сайта KSP. 
**Параметры**:  Нет.
**Возвращает**:  Нет.
**Вызывает исключения**: 
    - `WebDriverException`: Если возникает ошибка при взаимодействии с  `Webdriver`.
**Как работает функция**:
- Получает идентификатор Google Таблицы (`sh_id`) и корневой URL сайта KSP (`root`).
- Получает словарь категорий (`worlds_dic`)  с помощью функции  `ksp.get_worlds()`.
- Создает объект  `GSpreadsheet` для  Google Таблицы.
- Цикл по категориям:
    -  Создает  `GWorksheet` для  Google Таблицы, соответствующей категории.
    -  Устанавливает заголовок  столбцов в  `GWorksheet`.
    -  Переходит по URL  категории.
    -  Получает список  подкатегорий  с помощью функции  `ksp.get_subs_from_world()`.
    -  Цикл по  подкатегориям:
        -  Переходит по URL  подкатегории.
        -  Добавляет  строку с названием  категории в  `GWorksheet`.
        -  Получает список брендов  с помощью функции  `ksp.get_all_brands_list()`.
        -  Цикл по брендам:
            -  Добавляет  строку с  именем бренда и количеством товаров в  `GWorksheet`.

### `def get_all_spreadsheets()`

**Назначение**: Получает список всех Google Таблиц, доступных на текущем аккаунте. 
**Параметры**: Нет.
**Возвращает**: 
    - `list`:  Список  `GSpreadsheet` объектов.
**Вызывает исключения**: 
    - `gs.SpreadsheetException`: Если возникает ошибка при  взаимодействии  с  API Google Sheets.
**Как работает функция**: 
-  Использует модуль  `gs` для  получения списка всех Google Таблиц, доступных на текущем аккаунте.
-  Возвращает список  `GSpreadsheet` объектов.
