## Как использовать модуль `ksp.py`

=========================================================================================

Описание
-------------------------
Модуль `ksp.py` предоставляет функции для работы с веб-сайтом `ksp.co.il` с использованием библиотеки `selenium` через `webdriver`

Шаги выполнения
-------------------------
1. **Загрузка локаторов**: Модуль `ksp.py` использует файл `locators.json`, содержащий локаторы для элементов на странице. 
2. **Получение списка миров**: Функция `get_worlds()` извлекает список доступных миров (например, Израиль, США, Европа).
3. **Получение списка подкатегорий**: Функция `get_subs_from_world()` извлекает список подкатегорий товаров для выбранного мира.
4. **Получение списка брендов**: Функция `get_all_brands_list()` получает список всех брендов, доступных на сайте.
5. **Получение информации о товаре**: Функция `get_product(url: str)` получает информацию о товаре по указанному URL-адресу.

Пример использования
-------------------------

```python
from src.___beeryakov.suppliers.ksp import ksp

# Получение списка миров
worlds = ksp.get_worlds()
print(f'Доступные миры: {worlds}')

# Получение списка подкатегорий для Израиля
subs = ksp.get_subs_from_world()
print(f'Подкатегории товаров: {subs}')

# Получение списка брендов
brands = ksp.get_all_brands_list()
print(f'Список брендов: {brands}')

# Получение информации о товаре по URL
product_info = ksp.get_product(url='https://ksp.co.il/web/item/227307')
print(f'Информация о товаре: {product_info}')
```
