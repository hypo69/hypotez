## Как использовать этот блок кода
=========================================================================================

Описание
-------------------------
Блок кода реализует функцию `count_lines_in_files`, которая рекурсивно подсчитывает количество строк в текстовых файлах в указанном каталоге и его подкаталогах, а также количество классов и функций в этих файлах.

Шаги выполнения
-------------------------
1. Функция `count_lines_in_files` принимает в качестве аргумента путь к каталогу.
2. Функция перебирает все файлы и каталоги в указанном каталоге.
3. Для каждого файла проверяется, является ли он текстовым (не двоичным) и не относится ли к каталогам `__pycache__`, `firefox_profiles`, а также не является ли Jupyter Notebook файлом.
4. Для текстовых файлов подсчитывается количество строк, а также количество классов и функций в файле.
5. Для подкаталогов функция `count_lines_in_files` вызывается рекурсивно, чтобы подсчитать количество строк, классов и функций в файлах этих подкаталогов.
6. Все полученные значения суммируются, и в конце функция возвращает общее количество строк, классов и функций во всех файлах в каталоге и его подкаталогах.

Пример использования
-------------------------

```python
    src_directory = 'src'
    print(f"Counting lines, classes, and functions in files in directory: {src_directory}")
    total_lines, total_classes, total_functions = count_lines_in_files(src_directory)
    print(f"Total lines in text files in '{src_directory}': {total_lines}")
    print(f"Total classes: {total_classes}")
    print(f"Total functions: {total_functions}")
```

В этом примере код вызывается с аргументом `src_directory`, который указывает путь к каталогу "src". Функция `count_lines_in_files` подсчитывает количество строк, классов и функций в файлах в этом каталоге и его подкаталогах, а затем выводит эти значения на консоль.
