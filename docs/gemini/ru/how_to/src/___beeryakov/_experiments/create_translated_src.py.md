## Как использовать этот блок кода
=========================================================================================

Описание
-------------------------
Этот блок кода предназначен для копирования файлов из исходной папки в другую папку и проверки их кодировки. 
Он также выводит на консоль текст, написанный на русском языке.

Шаги выполнения
-------------------------
1. **Определение кодировки файла:** Функция `detect_language` считывает содержимое файла, определяет его кодировку с помощью библиотеки `chardet` и возвращает кодировку, если она соответствует UTF-8.
2. **Копирование файла:** Функция `copy_and_print_russian_text` перебирает все файлы в указанной исходной папке и копирует их в заданную папку назначения.
3. **Проверка кодировки и вывод текста:** Если кодировка файла соответствует UTF-8, функция читает содержимое файла и выводит его на консоль с помощью `print`.

Пример использования
-------------------------

```python
    # Путь к исходной папке
    src_folder = 'src'

    # Путь к папке, в которую будем копировать файлы
    dest_folder = 'src_en'

    # Вызываем функцию для копирования и вывода текста на русском языке
    copy_and_print_russian_text(src_folder, dest_folder)
```

В этом примере `src_folder` указывает на папку, содержащую файлы, которые нужно скопировать, а `dest_folder` - на папку, в которую они будут скопированы. Функция `copy_and_print_russian_text` копирует файлы и выводит на консоль текст из файлов, имеющих кодировку UTF-8.
