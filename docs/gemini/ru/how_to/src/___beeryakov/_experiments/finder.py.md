## Как использовать `find_categories`
=========================================================================================

Описание
-------------------------
Функция `find_categories(directory)` рекурсивно обходит заданную директорию и ищет папки или файлы, которые указывают на категории товаров. Она проверяет наличие подпапки "category" или файла "category.py" в каждой директории.

Шаги выполнения
-------------------------
1. Функция получает на вход строку с путем к директории (`directory`).
2. Используя `os.walk(directory)`, функция проходит по всем подкаталогам и файлам в заданной директории.
3. Для каждой директории функция проверяет, есть ли в ней папка "category" или файл "category.py".
4. Если папка "category" или файл "category.py" найдены, функция добавляет абсолютный путь к ним в список `categories`.
5. По завершении обхода всех подкаталогов функция возвращает список `categories`, содержащий пути к найденным категориям.

Пример использования
-------------------------

```python
    # Получаем путь к папке `src` проекта
    src = str(Path(gs.path.src))
    # Вызываем функцию `find_categories` с указанием пути к папке `src`
    found_categories = find_categories(src)
    # Выводим пути к найденным категориям
    for item in found_categories:
        print(item)
```

**Описание:**

- `gs.path.src` - это константа, хранящая путь к папке `src` проекта.
- В этом примере мы получаем путь к папке `src`, используя константу `gs.path.src`.
- Затем мы вызываем функцию `find_categories` с полученным путем к папке `src`, чтобы найти все категории товаров в проекте.
- В конце мы выводим найденные пути к категориям на консоль.
