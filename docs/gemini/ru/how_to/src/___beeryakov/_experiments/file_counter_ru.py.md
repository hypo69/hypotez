## Как использовать этот блок кода
=========================================================================================

Описание
-------------------------
Блок кода представляет собой функцию `count_lines_in_files`, которая рекурсивно подсчитывает количество строк в текстовых файлах в указанной директории и ее поддиректориях, а также количество классов и функций. 

Шаги выполнения
-------------------------
1. **Инициализация счетчиков**: Функция создает три счетчика: `total_lines`, `total_classes` и `total_functions` для хранения суммарного количества строк, классов и функций соответственно.
2. **Проход по файлам в директории**: Функция перебирает все файлы в заданной директории. 
3. **Проверка типа файла**:  Для каждого файла функция проверяет, является ли он текстовым и не является ли файл из папок `__pycache__` и `firefox_profiles`. Если файл не текстовый, функция переходит к следующему.
4. **Чтение файла**: Если файл является текстовым, функция открывает его для чтения и подсчитывает количество строк в нем.
5. **Подсчет классов и функций**: Функция вызывает `count_classes_and_functions` для подсчета количества классов и функций в текущем файле и увеличивает счетчики `total_classes` и `total_functions` соответствующими значениями.
6. **Рекурсивный вызов**: Если файл является директорией, функция рекурсивно вызывает саму себя для подсчета строк, классов и функций в этой директории.
7. **Возвращение результата**: После обработки всех файлов в директории, функция возвращает значения счетчиков `total_lines`, `total_classes` и `total_functions`.

Пример использования
-------------------------

```python
    src_directory = 'src'
    print(f"Подсчет строк, классов и функций в файлах в директории: {src_directory}")
    total_lines, total_classes, total_functions = count_lines_in_files(src_directory)
    print(f"Всего строк в текстовых файлах в \'{src_directory}\': {total_lines}")
    print(f"Всего классов: {total_classes}")
    print(f"Всего функций: {total_functions}")
