# Модуль для подсчета строк, классов и функций в файлах

## Обзор

Этот модуль предоставляет функции для рекурсивного подсчета количества строк, классов и функций в текстовых файлах, расположенных в заданной директории и ее поддиректориях. Модуль игнорирует бинарные файлы, файлы в папках `__pycache__` и `firefox_profiles`, а также файл `__init__.py`. 

## Детали

Модуль `file_counter_ru.py` предназначен для сбора информации о размере кода, в частности количества строк кода, классов и функций. Это полезно для оценки сложности и масштаба проекта. 

## Функции

### `count_lines_in_files(directory)`

**Цель**: Рекурсивно подсчитывает количество строк в текстовых файлах в указанной директории и ее поддиректориях, а также количество классов и функций.

**Параметры**:

- `directory` (str): Путь к директории.

**Возвращает**:

- `tuple`: Кортеж из трех значений:
    - `total_lines` (int): Общее количество строк в текстовых файлах.
    - `total_classes` (int): Общее количество классов.
    - `total_functions` (int): Общее количество функций.

**Как работает функция**:

- Функция проходит по всем файлам и поддиректориям в заданной директории.
- Для каждого файла проверяется, является ли он текстовым (не бинарным) и не находится ли он в папках `__pycache__` или `firefox_profiles`, а также не является ли он файлом `__init__.py`.
- Если файл соответствует критериям, функция считывает его содержимое и подсчитывает количество строк.
- Затем функция вызывает функцию `count_classes_and_functions` для подсчета количества классов и функций в файле.
- Для каждой поддиректории функция рекурсивно вызывается для подсчета строк, классов и функций в ней.
- В итоге функция возвращает общее количество строк, классов и функций.

**Примеры**:

```python
# Подсчет строк, классов и функций в директории 'src'
src_directory = 'src'
total_lines, total_classes, total_functions = count_lines_in_files(src_directory)
print(f"Всего строк в текстовых файлах в '{src_directory}': {total_lines}")
print(f"Всего классов: {total_classes}")
print(f"Всего функций: {total_functions}")
```


### `is_binary(filepath)`

**Цель**: Проверяет, является ли файл бинарным.

**Параметры**:

- `filepath` (str): Путь к файлу.

**Возвращает**:

- `bool`: True, если файл бинарный, иначе False.

**Как работает функция**:

- Функция пытается открыть файл в двоичном режиме (`'rb'`).
- Затем она читает первые 512 байт файла и проверяет, содержатся ли в них нулевые байты (`b'\\0'`).
- Если нулевые байты найдены, файл считается бинарным и функция возвращает `True`.
- Если при чтении файла возникает ошибка, файл также считается бинарным и функция возвращает `True`.

**Примеры**:

```python
# Проверка файла на бинарность
filepath = 'some_file.txt'
is_binary(filepath)
```


### `count_classes_and_functions(filepath)`

**Цель**: Подсчитывает количество классов и функций в файле.

**Параметры**:

- `filepath` (str): Путь к файлу.

**Возвращает**:

- `tuple`: Кортеж из двух значений:
    - `total_classes` (int): Количество классов.
    - `total_functions` (int): Количество функций.

**Как работает функция**:

- Функция открывает файл в режиме чтения (`'r'`).
- Затем она проходит по каждой строке файла и проверяет, начинается ли она с ключевого слова `'class'` или `'def'`.
- Если строка начинается с `'class'`, счетчик `total_classes` увеличивается на 1.
- Если строка начинается с `'def'`, счетчик `total_functions` увеличивается на 1.
- В итоге функция возвращает количество классов и функций в файле.

**Примеры**:

```python
# Подсчет классов и функций в файле
filepath = 'some_file.py'
total_classes, total_functions = count_classes_and_functions(filepath)
print(f"Количество классов в файле '{filepath}': {total_classes}")
print(f"Количество функций в файле '{filepath}': {total_functions}")
```

## Примеры использования

```python
# Подсчет строк, классов и функций в директории 'src'
src_directory = 'src'
total_lines, total_classes, total_functions = count_lines_in_files(src_directory)
print(f"Всего строк в текстовых файлах в '{src_directory}': {total_lines}")
print(f"Всего классов: {total_classes}")
print(f"Всего функций: {total_functions}")
```

```python
# Проверка файла на бинарность
filepath = 'some_file.txt'
is_binary(filepath)
```

```python
# Подсчет классов и функций в файле
filepath = 'some_file.py'

print(f"Количество классов в файле '{filepath}': {total_classes}")
print(f"Количество функций в файле '{filepath}': {total_functions}")
```

## Дополнительные замечания

- Модуль использует стандартные функции `os.listdir`, `os.path.isfile`, `os.path.isdir` для работы с файлами и директориями.
- Функция `count_lines_in_files` использует генератор для подсчета строк в файле, что делает ее более эффективной, чем чтение всех строк в список.
- Функция `is_binary` использует метод `file.read(512)` для чтения первых 512 байт файла, что достаточно для определения бинарности.
- Функция `count_classes_and_functions` использует метод `line.strip().startswith` для проверки начала строки на ключевые слова.
