## Быстрый старт

### 1. Создание нового поста

```python
from src.database.wordpress_models import Post, add_new_post
from src.database.wordpress_pymysql import WordPressDB, WordPressConfig

# Настройка подключения
config = WordPressConfig(host='localhost', database='wordpress', username='user', password='pass')
wp_db = WordPressDB(config)
wp_db.connect()

# Создание поста
new_post = Post(
    post_title='Мой новый пост',
    post_content='<p>Это содержимое поста</p>',
    post_status='publish',
    post_author=1,
    meta={
        '_custom_field': 'Пользовательское значение',
        '_seo_description': 'SEO описание'
    }
)

# Добавление поста
post_id = add_new_post(wp_db, new_post)
if post_id:
    print(f'Пост создан с ID: {post_id}')
```

### 2. Обновление поста

```python
from src.database.wordpress_models import get_post_by_id, update_post

# Получение поста
post = get_post_by_id(wp_db, post_id)
if post:
    # Изменение данных
    post.post_title = 'Обновленный заголовок'
    post.post_content += '\n<p>Дополнительный контент</p>'
    post.meta['_updated'] = 'true'
    
    # Сохранение изменений
    if update_post(wp_db, post):
        print('Пост обновлен')
```

### 3. Удаление поста

```python
from src.database.wordpress_models import delete_post

# Мягкое удаление (в корзину)
if delete_post(wp_db, post_id, force_delete=False):
    print('Пост перемещен в корзину')

# Полное удаление
if delete_post(wp_db, post_id, force_delete=True):
    print('Пост удален навсегда')
```

## Все поля класса Post

### Основные поля WordPress

| Поле | Тип | Описание |
|------|-----|----------|
| `ID` | Optional[int] | Уникальный идентификатор поста |
| `post_author` | int | ID автора поста |
| `post_date` | datetime | Дата создания поста |
| `post_date_gmt` | datetime | Дата создания по GMT |
| `post_content` | str | Основное содержимое поста |
| `post_title` | str | Заголовок поста |
| `post_excerpt` | str | Краткое описание поста |
| `post_status` | str | Статус (publish, draft, private, pending, trash) |
| `comment_status` | str | Статус комментариев (open, closed) |
| `ping_status` | str | Статус пингов (open, closed) |
| `post_password` | str | Пароль для защищенного поста |
| `post_name` | str | URL-слаг поста |
| `post_modified` | datetime | Дата последнего изменения |
| `post_parent` | int | ID родительского поста |
| `guid` | str | Глобальный уникальный идентификатор |
| `menu_order` | int | Порядок сортировки |
| `post_type` | str | Тип поста (post, page, custom) |
| `comment_count` | int | Количество комментариев |

### Дополнительные поля

| Поле | Тип | Описание |
|------|-----|----------|
| `meta` | Dict[str, Any] | Пользовательские метаданные |

## Статусы постов

### Доступные статусы

- `publish` - Опубликован
- `draft` - Черновик  
- `private` - Приватный
- `pending` - Ожидает модерации
- `trash` - В корзине
- `auto-draft` - Автосохранение
- `inherit` - Наследует от родителя

### Пример работы со статусами

```python
# Создание черновика
draft_post = Post(
    post_title='Черновик поста',
    post_content='Содержимое черновика',
    post_status='draft'
)

# Публикация черновика
draft_post.post_status = 'publish'
draft_post.update(wp_db)

# Перемещение в приватные
draft_post.post_status = 'private' 
draft_post.update(wp_db)
```

## Обработка ошибок

Все методы автоматически обрабатывают ошибки:

```python
# Метод автоматически логирует ошибки и возвращает False/None
post_id = add_new_post(wp_db, post)
if not post_id:
    print('Ошибка при создании поста (проверьте логи)')

# То же самое с обновлением
if not update_post(wp_db, post):
    print('Ошибка при обновлении поста')
```

### 3. Валидация данных

```python
def create_validated_post(title, content, author_id=1):
    if not title or len(title) < 3:
        raise ValueError('Заголовок должен содержать минимум 3 символа')
    
    if not content or len(content) < 10:
        raise ValueError('Содержимое должно содержать минимум 10 символов')
    
    return Post(
        post_title=title.strip(),
        post_content=content.strip(),
        post_author=author_id,
        post_status='draft'  # Безопасный статус по умолчанию
    )
```

def process_posts_batch(wp_db, posts_data, batch_size=50):
