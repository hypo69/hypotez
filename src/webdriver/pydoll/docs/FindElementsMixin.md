# `FindElementsMixin` Class Reference

`FindElementsMixin` — это [миксин (mixin)](https://ru.wikipedia.org/wiki/Примесь_(программирование)), который предоставляет исчерпывающий набор методов для поиска DOM-элементов на веб-странице. Он не предназначен для самостоятельного использования, а "подмешивается" к другим классам, таким как `Tab` и `WebElement`, чтобы наделить их мощными возможностями поиска.

Этот класс инкапсулирует всю сложность, связанную с:
-   Поиском одного или нескольких элементов.
-   Использованием различных стратегий поиска (CSS, XPath, ID, class и т.д.).
-   Асинхронным ожиданием появления элементов на странице в течение заданного времени.
-   Поиском элементов как в контексте всей страницы (когда используется в `Tab`), так и внутри другого элемента (когда используется в `WebElement`).

---

## Публичные методы

Это методы, которые вы будете использовать чаще всего при работе с классами, унаследовавшими этот миксин (например, `tab.find(...)` или `element.query(...)`).

### `find(...)`

Находит элемент(ы) по комбинации стандартных HTML-атрибутов. Это наиболее удобный и читаемый способ для большинства поисковых запросов. Если вы указываете несколько атрибутов, миксин автоматически конструирует сложный XPath-запрос для более точного поиска.

-   **Параметры:**
    -   `id` (`Optional[str]`): Значение атрибута `id`.
    -   `class_name` (`Optional[str]`): Имя CSS-класса.
    -   `name` (`Optional[str]`): Значение атрибута `name`.
    -   `tag_name` (`Optional[str]`): Имя HTML-тега (например, `"div"`, `"a"`).
    -   `text` (`Optional[str]`): Текст, который должен содержаться внутри элемента.
    -   `timeout` (`int`): Максимальное время в секундах для ожидания появления элемента. По умолчанию `0` (без ожидания).
    -   `find_all` (`bool`): Если `True`, возвращает список всех найденных элементов. Если `False` (по умолчанию), возвращает только первый.
    -   `raise_exc` (`bool`): Если `True` (по умолчанию), вызывает исключение (`ElementNotFound` или `WaitElementTimeout`), если элемент не найден. Если `False`, возвращает `None` или пустой список.
    -   `**attributes` (`dict[str, str]`): Дополнительные атрибуты для поиска (например, `data_test_id="login-button"`).

-   **Возвращаемое значение:** Тип зависит от комбинации `find_all` и `raise_exc`.

| `find_all` | `raise_exc` | Возвращаемый тип | Описание |
| :--- | :--- | :--- | :--- |
| `False` | `True` | `WebElement` | Находит первый элемент, иначе исключение. |
| `False` | `False` | `Optional[WebElement]` | Находит первый элемент, иначе `None`. |
| `True` | `True` | `list[WebElement]` | Находит все элементы, иначе исключение. |
| `True` | `False` | `Optional[list[WebElement]]` | Находит все элементы (список может быть пустым).|

-   **Примеры:**
    ```python
    # Найти первую кнопку с классом 'btn-primary'
    button = await tab.find(tag_name='button', class_name='btn-primary')

    # Найти все элементы списка li с текстом "Item" внутри, подождать 5 секунд
    items = await tab.find(tag_name='li', text='Item', find_all=True, timeout=5)
    ```

### `query(...)`

Находит элемент(ы) с помощью "сырого" CSS-селектора или XPath-выражения. Тип селектора (CSS или XPath) определяется автоматически по его синтаксису.

-   **Параметры:**
    -   `expression` (`str`): Строка CSS-селектора (например, `"#main .content p"`) или XPath (`//div[@id="main"]//p`).
    -   `timeout`, `find_all`, `raise_exc`: Аналогичны методу `find`.

-   **Возвращаемое значение:** Аналогично методу `find`.

-   **Примеры:**
    ```python
    # Поиск по CSS-селектору
    header = await tab.query('header#page-header > h1')

    # Поиск по XPath
    login_form = await tab.query('//form[@id="login"]')
    ```

## Основной логический метод

### `find_or_wait_element(...)`

Это "движок", который используют публичные методы `find()` и `query()`. Он выполняет поиск элемента с возможностью ожидания. Если `timeout` > 0, метод будет циклически (с задержкой 0.5 секунды) пытаться найти элемент, пока не найдет его или пока не истечет время ожидания.

Обычно вам не нужно вызывать его напрямую, но это возможно, если у вас уже есть готовая стратегия `By` и значение.

-   **Параметры:**
    -   `by` (`By`): Стратегия поиска (например, `By.CSS_SELECTOR`, `By.XPATH`).
    -   `value` (`str`): Значение селектора.
    -   `timeout`, `find_all`, `raise_exc`: Аналогичны методам выше.

## Внутренняя реализация (упрощенно)

1.  **Вызов `find()` или `query()`:** Пользователь вызывает один из высокоуровневых методов.
2.  **Определение стратегии:**
    -   `find()` анализирует переданные атрибуты и с помощью `_build_xpath()` создает либо простой селектор, либо сложное XPath-выражение.
    -   `query()` с помощью `_get_expression_type()` определяет, является ли строка CSS-селектором или XPath.
3.  **Вызов `find_or_wait_element()`:** Оба метода передают полученную стратегию (`By`) и значение в `find_or_wait_element()`.
4.  **Поиск и ожидание:**
    -   `find_or_wait_element()` организует цикл ожидания. Внутри цикла он вызывает низкоуровневые методы `_find_element()` или `_find_elements()`.
5.  **Формирование и выполнение команды CDP:**
    -   Методы `_find_element(s)` создают JavaScript-код для поиска элемента в браузере (например, `document.querySelector(...)` или `document.evaluate(...)`).
    -   Этот код упаковывается в команду Chrome DevTools Protocol (CDP) и отправляется в браузер через метод `_execute_command()`. **Важно:** метод `_execute_command()` должен быть реализован в классе, который использует этот миксин (например, в `Tab` или `WebElement`).
6.  **Создание экземпляров `WebElement`:**
    -   Браузер возвращает `objectId` найденных элементов.
    -   Миксин использует эти ID для получения дополнительной информации (атрибуты, имя тега) и с помощью фабричной функции `create_web_element()` создает и возвращает экземпляры `WebElement`.
