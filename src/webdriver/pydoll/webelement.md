
# `WebElement` Class Reference

Класс `WebElement` представляет собой обертку для одного элемента DOM на веб-странице. Он предоставляет полный набор методов для взаимодействия с элементом (клики, ввод текста), его инспекции (получение атрибутов, текста) и манипуляций с ним с помощью команд Chrome DevTools Protocol (CDP).

**Примечание по поиску элементов:** Этот класс наследуется от `FindElementsMixin`, что позволяет ему выполнять поиск других элементов *внутри* него самого. Например, `form_element.find(id='submit-button')` будет искать кнопку только в пределах `form_element`.

---

## Свойства

### `value`
Возвращает значение атрибута `value` элемента. Полезно для элементов форм, таких как `<input>`, `<option>`, `<textarea>`.
- **Тип:** `Optional[str]`

### `class_name`
Возвращает строку, содержащую все CSS-классы элемента (атрибут `class`).
- **Тип:** `Optional[str]`

### `id`
Возвращает значение атрибута `id` элемента.
- **Тип:** `Optional[str]`

### `tag_name`
Возвращает имя HTML-тега элемента в нижнем регистре (например, `div`, `a`, `input`).
- **Тип:** `Optional[str]`

### `is_enabled`
Определяет, активен ли элемент. Возвращает `False`, если у элемента есть атрибут `disabled`.
- **Тип:** `bool`

### `text`
Возвращает видимый текстовый контент элемента и всех его дочерних элементов, без HTML-тегов.
- **Тип:** `str` (асинхронное свойство)

### `bounds`
Возвращает координаты ограничивающего прямоугольника элемента (bounding box) относительно левого верхнего угла документа.
- **Тип:** `Quad` (псевдоним для списка координат `[x1, y1, x2, y2, ...]`) (асинхронное свойство)

### `inner_html`
Возвращает полный HTML-код элемента, включая сам элемент (аналог `outerHTML` в JavaScript).
- **Тип:** `str` (асинхронное свойство)

## Методы

### `get_attribute(name: str)`
Получает значение указанного HTML-атрибута элемента.
- **Параметры:**
  - `name` (`str`): Имя атрибута (например, `href`, `src`, `aria-label`).
- **Возвращает:**
  - `Optional[str]`: Значение атрибута или `None`, если он отсутствует.
- **Примечание:** Возвращает значение, которое было у атрибута в момент поиска элемента. Для получения динамически измененных значений используйте `execute_script`.

### `get_bounds_using_js()`
Получает координаты элемента с помощью JavaScript-метода `getBoundingClientRect()`. В отличие от `bounds`, координаты возвращаются относительно видимой области окна (viewport).
- **Возвращает:**
  - `dict[str, int]`: Словарь с ключами `x`, `y`, `width`, `height`.

### `get_parent_element()`
Находит и возвращает родительский элемент для текущего элемента.
- **Возвращает:**
  - `WebElement`: Экземпляр родительского элемента.
- **Вызывает:**
  - `ElementNotFound`: Если родительский элемент не найден.

### `take_screenshot(path: str, quality: int = 100)`
Делает скриншот только этого конкретного элемента. Элемент автоматически прокручивается в видимую область перед созданием снимка.
- **Параметры:**
  - `path` (`str`): Путь для сохранения `.jpg` файла.
  - `quality` (`int`): Качество изображения (0-100).

### `scroll_into_view()`
Прокручивает страницу так, чтобы элемент стал видимым в окне браузера.

### `click(x_offset: int = 0, y_offset: int = 0, hold_time: float = 0.1)`
Имитирует полноценный клик мыши по центру элемента. Это наиболее реалистичный способ клика.
- **Параметры:**
  - `x_offset` (`int`), `y_offset` (`int`): Смещение от центра элемента в пикселях.
  - `hold_time` (`float`): Время в секундах, на которое "зажимается" кнопка мыши.
- **Вызывает:**
  - `ElementNotVisible`: Если элемент невидим.

### `click_using_js()`
Выполняет клик с помощью вызова JavaScript-метода `element.click()`. Это может работать для элементов, которые перекрыты другими, но не всегда вызывает те же события, что и настоящий клик.
- **Вызывает:**
  - `ElementNotVisible`: Если элемент невидим.
  - `ElementNotInteractable`: Если клик не удался.

### `insert_text(text: str)`
Мгновенно вставляет весь текст в элемент. Это быстрый, но менее реалистичный способ ввода.
- **Примечание:** Элемент должен быть в фокусе.

### `type_text(text: str, interval: float = 0.1)`
Имитирует посимвольный ввод текста с клавиатуры с задержкой между символами. Это более медленный, но самый реалистичный способ ввода.
- **Параметры:**
  - `text` (`str`): Текст для ввода.
  - `interval` (`float`): Задержка в секундах между нажатиями клавиш.

### `set_input_files(files: list[str])`
Устанавливает пути к файлам для элемента `<input type="file">`.
- **Параметры:**
  - `files` (`list[str]`): Список абсолютных путей к файлам.
- **Вызывает:**
  - `ElementNotAFileInput`: Если элемент не является полем для загрузки файлов.

### `key_down(key: Key, modifiers: Optional[KeyModifier] = None)`
Имитирует нажатие (но не отпускание) клавиши на клавиатуре.
- **Параметры:**
  - `key` (`Key`): Специальная клавиша из `pydoll.constants.Key` (например, `Key.ENTER`).
  - `modifiers` (`KeyModifier`): Клавиши-модификаторы (`SHIFT`, `CTRL` и т.д.).

### `key_up(key: Key)`
Имитирует отпускание ранее нажатой клавиши.

### `press_keyboard_key(key: Key, ..., interval: float = 0.1)`
Выполняет полный цикл нажатия и отпускания специальной клавиши. Это предпочтительный метод для отправки команд, таких как Enter, Tab, Escape и т.д.
- **Параметры:**
  - `key` (`Key`): Клавиша для нажатия.
  - `modifiers` (`KeyModifier`): Модификаторы.
  - `interval` (`float`): Пауза между нажатием и отпусканием.

### `__repr__`
Возвращает строковое представление объекта, включающее имя класса, все его атрибуты и уникальный `objectId` от CDP, что очень полезно для отладки.
- **Пример вывода:** `WebElement(class='btn btn-primary', id='submit', tag_name='button')(object_id=-1)`
